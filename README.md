# makie

> the chatty bot

Makie replies to Instagram links with embeddable `kkinstagram.com` links,
including links shared without mentioning the bot. Enable **Message Content
Intent** for the bot in the Discord Developer Portal before starting it.

This Storyden plugin workspace was created by the plugin builder robot.

Use the robot tools to edit files, run gofmt, run go vet, run go test, package,
and install the plugin as a supervised Storyden plugin.
